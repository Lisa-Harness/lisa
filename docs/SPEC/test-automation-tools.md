## Tool Summaries

### DeepEval — Primary Test Framework

- **Purpose:** Define, run, and assert LLM behavior using custom and built-in metrics.
- **Strengths:**
  - Pytest-compatible, fits existing CI pipelines.
  - Supports custom metrics, dataset management, and golden datasets.
  - Rich assertion library for faithfulness, relevance, toxicity, and more.
- **Use in `lisa_framework`:**
  - Author test cases as pytest functions decorated with DeepEval metrics.
  - Gate merges on metric thresholds.
  - Maintain regression suites for prompt and model changes.

### Promptfoo — Rapid Experimentation

- **Purpose:** Compare prompts, models, and configurations quickly with minimal boilerplate.
- **Strengths:**
  - YAML/JSON config-driven test definitions.
  - Built-in support for multiple providers and side-by-side output comparison.
  - Fast iteration cycle for prompt engineering.
- **Use in `lisa_framework`:**
  - Prototype and benchmark prompt variants before promoting them to DeepEval suites.
  - Generate candidate test cases from real outputs.
  - Share reproducible prompt configs across the team.

### Langfuse — Observability

- **Purpose:** Trace, log, and monitor LLM calls in development and production.
- **Strengths:**
  - Open-source, self-hostable.
  - Captures prompts, generations, scores, and user feedback.
  - Integrates with evaluation workflows for post-hoc analysis.
- **Use in `lisa_framework`:**
  - Instrument `lisa_framework` calls to emit traces.
  - Correlate CI test runs with production behavior.
  - Feed observed failures back into DeepEval as new test cases.

## Integration Points

### DeepEval ↔ `lisa_framework`

- Wrap `lisa_framework` entry points in DeepEval test functions.
- Map framework outputs to DeepEval metrics:
  - `answer_relevance`
  - `faithfulness`
  - `custom` metrics for domain-specific checks
- Store golden datasets alongside framework configs.

### Promptfoo ↔ `lisa_framework`

- Export `lisa_framework` prompt templates into Promptfoo config files.
- Use Promptfoo providers to call `lisa_framework` endpoints or functions directly.
- Promote winning configs back into the framework’s prompt registry.

### Langfuse ↔ `lisa_framework`

- Add Langfuse SDK calls at key boundaries:
  - Prompt rendering
  - Model invocation
  - Post-processing / response formatting
- Attach metadata: prompt version, test run ID, environment.
- Export scored traces to inform DeepEval test expansion.
