# SDK Packs

Inherits all rules in `.github/instructions/python-development.md` and
`.github/instructions/code-quality.md`. The rules below are additive and
specific to `sdk_packs/`.

## Content-first

- Packs are primarily Markdown (`.operation.md`, `.mode.md`) and YAML
  (`.yml` metadata). Python files exist only for response-format Pydantic
  models or thin runtime operation handlers.
- A runtime operation handler (`execution_kind="runtime"`) must be a single
  callable that accepts an `OperationExecutionContext` and returns an
  `OperationResult`. No framework logic, no routing, no state management.

## Operation authoring

- Each `operation_id` appears only once across all roots. Markdown operations
  take precedence over Python when both exist for the same id.
- Operations must be discoverable without side effects on import.
- Follow `docs/PACK_AUTHORING_GUIDE.md` for mode and operation file structure.
