# MCP server guidance

- Keep first-party MCP servers thin transport facades. Put domain logic in the SDK instead of embedding it in server modules.
- Preserve the parser/CLI contract for each server entry point and keep path handling explicit through the provided data-dir contract.
- Avoid coupling server modules to host runtime concerns; keep them focused on transport and tool exposure.
