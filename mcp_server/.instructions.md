# Lisa MCP Servers

Inherits all rules in `.github/instructions/python-development.md` and
`.github/instructions/code-quality.md`. The rules below are additive and
specific to `mcp_server/`.

## Boundary

- `mcp_server` may import from `kernel` and `sdk` but must not import from
  `hosts/` or host runtime modules.
- Server subpackages (`context`, `memory`, `guard`, `content`) must not
  import each other. Shared CLI helpers live in `mcp_server/config/`.

## Server contract

- Every server must call `mcp_server.config.cli.build_parser(server_name)` in
  `main()` and require `--data-dir`.
- Entry-point targets are registered in `mcp_server/pyproject.toml`
  `[project.scripts]`.
- No env-var path resolution — all paths come from `--data-dir`.
