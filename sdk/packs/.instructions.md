# Pack development guidance

- Keep packs self-contained and host-neutral. Prefer thin runtime handlers over embedding orchestration concerns.
- Preserve the existing discovery and registration pattern for operations and tools.
- Keep pack content and runtime behavior aligned so the catalog can discover operations without side effects.
- Avoid cross-pack imports; promote shared helpers into the SDK when needed.
