# Lisa SDK Package

Inherits all rules in `.github/instructions/python-development.md` and
`.github/instructions/code-quality.md`. The rules below are additive and
specific to `sdk/`.

## Import boundary

- `sdk` may import from `kernel` but **must not** import from `hosts/`
  or any host application module.
- `sdk` sub-packages (`context`, `memory`, `content`, `packs/`) must not import each other circularly. If a cross-subpackage
  dependency is needed, define the shared type in `kernel` and import from
  there.

## Author-facing surface

- Public helpers must be importable without side effects (no registration on
  import, no env-var reads at module top level).
- Configuration helpers accept explicit parameters; do not read environment
  variables inside helper bodies. Let the host pass resolved values.
- Re-exports in `sdk/__init__.py` must be explicit (`from x import Y`),
  not wildcard.
