# SDK package guidance

- Keep SDK helpers generic and dependency-light. They should stay reusable rather than embedding host-specific behavior.
- Preserve the existing boundary between SDK domain logic and first-party MCP transport facades.
- Keep file and fetch primitives explicit about sandboxing and policy rather than relying on callers to enforce it.
- Prefer simple, import-safe helpers with explicit parameters over environment-driven behavior.
