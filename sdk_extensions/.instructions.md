# SDK Extensions

Inherits all rules in `.github/instructions/python-development.md` and
`.github/instructions/code-quality.md`. The rules below are additive and
specific to `sdk_extensions/`.

## Extension isolation

- Each extension (`clarity`, `cloudflare`, `github`, `stripe`) is self-contained.
- An extension may import from `kernel` and `lisa_sdk` but **must not** import
  from another extension or from `examples/`.
- If two extensions need a shared helper, promote it to `lisa_sdk`, not a
  cross-import.

## Entry points

- Each extension registers its content roots via the
  `lisa.extensions.content_roots` entry-point group in its `pyproject.toml`.
- Entry-point loading must be side-effect-free on import; registration happens
  only when the entry point is iterated by the host.
- API keys and credentials are always passed in by the host — never read from
  env inside extension modules.
