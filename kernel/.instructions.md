# Kernel package guidance

- Keep the kernel runtime-neutral. Do not introduce host- or SDK-specific imports into kernel modules.
- Preserve the existing contract-style abstractions in kernel modules rather than falling back to ad hoc state bags.
- Follow the slice and turn-runner patterns already established in the package when changing orchestration behavior.
- Keep handoff, approval, and routing logic explicit and testable.
