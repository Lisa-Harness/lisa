# Kernel Package

Inherits all rules in `.github/instructions/python-development.md` and
`.github/instructions/code-quality.md`. The rules below are additive and
specific to `kernel/`.

## Runtime neutrality (hard boundary)

- The kernel **must not** import from `hosts/`, `sdk/`,
  `sdk/packs/`, or any host application module.
- The kernel defines contracts; hosts inject wiring. Never add host-specific
  defaults or side effects to kernel modules.
- If a new dependency on a host or SDK surface appears, stop — it is an
  architecture violation. Move the logic to the host or SDK layer.

## Contract discipline

- Public surfaces are Pydantic models, `Protocol` classes, or `@dataclass`
  types. Mutable state bags (`dict[str, Any]`) are not permitted in the kernel
  — use a typed model.
- Protocols use `runtime_checkable` only when the consumer needs `isinstance`
  checks. Otherwise prefer structural typing.
- Operations registered via `register_operation_roots` must be discoverable
  without side effects on import.

## Slice model

- The slice contract in `kernel/slice.py` is the canonical expression of the
  opportunistic, pressure-driven work pattern. Do not introduce wall-clock
  timers or background schedulers in the kernel.
- Budget is a function of time since the last slice finished, not a tick.
