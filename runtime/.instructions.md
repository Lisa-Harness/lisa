# Host runtime guidance

- Keep the host runtime transport-neutral. Do not introduce transport-specific rendering logic into the shared runtime layer.
- Preserve the existing separation between configuration, runtime state, and callback delivery.
- Keep lifecycle and MCP integration explicit so resources are started and closed in the correct event loop.
- Prefer focused modules and thin dispatch paths over growing one large handler.
